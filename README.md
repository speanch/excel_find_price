# Декодирование «Эластичного бустинга» Ozon

Скрипт декодирует и сравнивает выгрузки «Эластичный бустинг» Ozon (файлы `products-*.xlsx`).

Столбцы BC–BI в листе «Товары и цены» — это XOR-замаскированные копии значений, которые уже есть в открытых столбцах. Скрипт их расшифровывает и сравнивает бустинг между несколькими выгрузками.

## Запуск

```
pip install openpyxl
python analyze_boost.py *.xlsx
python analyze_boost.py *.xlsx --out boost_compare.csv
```

## Примечание о конфиденциальности

Исходные выгрузки `products-*.xlsx` содержат данные магазина и в репозиторий не входят.
